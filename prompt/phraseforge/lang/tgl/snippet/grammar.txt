Grammar tags is an ordered string of space-separated tags, written exactly as listed (tags are case sensitive):

Part of speech (always capitalized):
  N = Noun: bahay, aso
  V = Verb: magsalita, kumain
  Adj = Adjective: maliit, maganda
  Adv = Adverb: kahapon, mabuti
  Pron = Pronoun: ako, siya
  Prep = Preposition: sa, para
  Conj = Conjunction: at, pero
  Num = Numeral: dalawa, tatlo
  Part = Particle: na, ba, pa
  Interj = Interjection: naku, aray
  Ph = Fixed phrase or idiom

Examples (phrase -> tags):
bahay -> N
magsalita -> V
maliit -> Adj
sa -> Prep
