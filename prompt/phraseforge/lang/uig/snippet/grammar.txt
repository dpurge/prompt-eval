Grammar tags is an ordered string of space-separated tags, written exactly as listed (tags are case sensitive):

Part of speech (always capitalized):
  N = Noun: ئۆي، كىتاب
  V = Verb: ئوقۇماق، بارماق
  Adj = Adjective: چوڭ، ياخشى
  Adv = Adverb: بۈگۈن، كۆپ
  Pron = Pronoun: مەن، ئۇ
  Post = Postposition: ئۈچۈن، بىلەن
  Conj = Conjunction: ۋە، لېكىن
  Num = Numeral: بىر، ئۈچ
  Part = Particle: مۇ، چۇ
  Interj = Interjection: ئاھ، ۋاي
  Ph = Fixed phrase or idiom

Examples (phrase -> tags):
ئۆي -> N
ئوقۇماق -> V
چوڭ -> Adj
ئۈچۈن -> Post
