Grammar tags is an ordered string of space-separated tags, written exactly as listed (tags are case sensitive):

Part of speech (always capitalized):
  N = Noun (нэр үг): гэр, ном
  V = Verb (үйл үг): бичих, явах
  Adj = Adjective (тэмдэг нэр): том, сайн
  Adv = Adverb (дайвар үг): өчигдөр, сайн
  Pron = Pronoun (төлөөний үг): би, тэр
  Post = Postposition: дээр, тухай
  Conj = Conjunction (холбоос): ба, гэхдээ
  Num = Numeral (тооны нэр): нэг, гурав
  Part = Particle: уу, ч
  Interj = Interjection: аа, өө
  Ph = Fixed phrase or idiom

Examples (phrase -> tags):
гэр -> N
бичих -> V
том -> Adj
дээр -> Post
