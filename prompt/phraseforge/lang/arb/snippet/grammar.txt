Grammar tags is an ordered string of space-separated tags:

Part of speech (always capitalized):
  Ph = phrase, fixed expression or idiom
  N = noun (اِسْم): كِتَابٌ
  V = verb (فِعْل): كَتَبَ
  Adj = adjective (صِفَة / نَعْت): كَبِيرٌ
  Adv = adverb (ظَرْف): أَمْسِ, هُنَا
  Pron = pronoun (ضَمِير): هُوَ, أَنَا
  Prep = preposition (حَرْف جَرّ): إِلَى, عَلَى
  Conj = conjunction (عَطْف): وَ, أَوْ
  Part = particle (أداة): لا
  Det = determiner (مُحَدِّد): الـ
  Num = numeral (عَدَد): ثَلَاثَةٌ
  Int = interrogative (اِسْتِفْهَام): مَنْ, مَتَى
  Interj = interjection (تَعَجُّب / نِدَاء): أُفّ
  PropN = Proper noun: مُحَمَّد، مِصْر
  Dem = Demonstrative: هَذَا، ذَلِكَ
  Rel = Relative pronoun: الَّذِي، الَّتِي
  Neg = Negation: لَا، لَمْ، لَنْ
  IntP = Interrogative particle: هَلْ، أَ
  IntN = Interrogative noun: مَنْ، مَا
  IntAdv = Interrogative adverb: أَيْنَ، مَتَى، كَيْفَ
  Aux = Auxiliary verb: كَانَ (in auxiliary use)
  Modal = Modal: يَجِبُ، يُمْكِنُ
  Ger = Verbal noun (maṣdar): كِتَابَةٌ
  Art = Definite article: الـ
  Poss = Possessive marker: ـهُ، ـهَا (possessive suffixes)

- Gender (always lower case):
  m = masculine
  f = feminine

- Number (always lower case):
  sg = singular
  pl = plural
  du = dual

Core tags = Ph, N, V, Adj, Adv, Pron, Prep, Conj, Num, Part, Int, Neg
Optional specialized tags (prefer to core tags): PropN, Dem, Rel, IntP, IntN, IntAdv, Art, Aux, Modal, Ger, Poss

Tags after:
- noun: gender, number
- adjective: gender, number
- pronoun: gender, number
- numeral: gender
- everything else: nothing

Examples (phrase -> tags):
مُبَرْمِجٌ -> N m sg
نِهَايَةٌ -> N f sg
كَتَبَ -> V
كَانَ -> V
كَبِيرٌ -> Adj m sg
