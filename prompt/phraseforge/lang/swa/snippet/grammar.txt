Grammar tags is an ordered string of space-separated tags, written exactly as listed (tags are case sensitive):

Part of speech (always capitalized):
  N = Noun: mtoto, kitabu
  V = Verb: kusema, kuona
  Adj = Adjective: mkubwa, mzuri
  Adv = Adverb: leo, jana
  Pron = Pronoun: mimi, yeye
  Prep = Preposition: kwa, katika
  Conj = Conjunction: na, lakini
  Num = Numeral: mbili, tatu
  Part = Particle: si, ni
  Interj = Interjection: lo, ee
  Ph = Fixed phrase or idiom

Examples (phrase -> tags):
mtoto -> N
kusema -> V
mkubwa -> Adj
leo -> Adv
