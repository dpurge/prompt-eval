Grammar tags is an ordered string of space-separated tags, written exactly as listed (tags are case sensitive):

Part of speech (always capitalized):
  N = Noun (isim): ev, kitap
  V = Verb (fiil): konuşmak, görmek
  Adj = Adjective (sıfat): küçük, iyi
  Adv = Adverb (zarf): dün, çok
  Pron = Pronoun (zamir): ben, o
  Post = Postposition (edat): için, ile
  Conj = Conjunction (bağlaç): ve, ama
  Num = Numeral (sayı): iki, üç
  Part = Particle: mi, de
  Interj = Interjection (ünlem): ah, vay
  Ph = Fixed phrase or idiom

Examples (phrase -> tags):
ev -> N
konuşmak -> V
küçük -> Adj
için -> Post
