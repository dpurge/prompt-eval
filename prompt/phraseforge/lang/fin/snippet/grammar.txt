Grammar tags is an ordered string of space-separated tags, written exactly as listed (tags are case sensitive):

Part of speech (always capitalized):
  N = Noun (substantiivi): koira, talo
  V = Verb (verbi): puhua, nähdä
  Adj = Adjective (adjektiivi): pieni, hyvä
  Adv = Adverb (adverbi): eilen, hyvin
  Pron = Pronoun (pronomini): minä, hän
  Prep = Preposition (prepositio): ilman, ennen
  Post = Postposition (postpositio): kanssa, jälkeen
  Conj = Conjunction (konjunktio): ja, mutta
  Num = Numeral (numeraali): kaksi, kolme
  Part = Particle (partikkeli): ei, vain
  Interj = Interjection (interjektio): voi, hei
  Ph = Fixed phrase or idiom

Examples (phrase -> tags):
koira -> N
puhua -> V
pieni -> Adj
ilman -> Prep
kanssa -> Post
